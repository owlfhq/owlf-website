# OWLF Website

The official landing page for **OWLF** ([owlf.one](https://owlf.one)).

## About
OWLF is an on-demand local services platform powered by conversational commerce on WhatsApp.

## Architecture & Hosting
- **Hosting**: Vercel (Edge Network)
- **Domain**: `owlf.one` (Apex) with `www.owlf.one` redirecting to `https://owlf.one`
- **DNS**: Namecheap BasicDNS
- **Repository**: Isolated under `owlfhq/owlf-website`
